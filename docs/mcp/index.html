Synthlings / MCP server

A music MCP server for your AI agent

Free · MIT · Node 22 · stdio · no keys

Your agent takes a seat in a band of AI characters (harmony, rhythm or arrangement) and writes a song with them, one move per turn. A judge checks every move against genre rules, and the song is rendered with free synths.

claude mcp add synthlings -- npx -y synthlings
Full guide npm GitHub

Install

Claude Code

claude mcp add synthlings -- npx -y synthlings

Claude Desktop, Cursor, Windsurf and most other clients

Add this to the client's MCP config file:

{
  "mcpServers": {
    "synthlings": { "command": "npx", "args": ["-y", "synthlings"] }
  }
}

VS Code

code --add-mcp '{"name":"synthlings","command":"npx","args":["-y","synthlings"]}'

Then ask your agent to call how_to_play. Sessions are saved in ~/.synthlings.

What your agent does

A band has three seats. Your agent can take one, two or all three; the house characters play the rest. Each move is one tool call: set the key or chords, write a drum, bass or hook part, place parts in sections, reshape the song's form, or change the mix. Every move carries a public note to the band and a private intent. After the build phase, one move in four has to take something out, so songs can't just pile up.

The judge checks every song. A quality floor always has to pass (a tempo and key that fit the genre, real chord changes, a sensible length). Genre conventions can be broken on purpose with a wildcard, and the judge records why.

Tools

how_to_playSeats, turns, the judge and the rules.
list_bandsThe bands, their seats and house characters, and genres with tempo ranges.
start_sessionStarts a song and seats your characters.
get_turnEverything a character sees on its turn: tools, libraries, the song so far, the judge.
make_moveOne move. A rejected move says what to fix.
listenPaths to the newest audio.
finish_songRenders the master once every move is played.
list_sessionsEvery session on this machine.

Cost and safety

  • Free and open source (MIT). No API keys, no account, no network access.
  • It only reads and writes its own folder, ~/.synthlings.
  • Moves and judging work straight away. To hear the songs, install the free studio (Python, ffmpeg, FluidSynth and Surge XT); see the guide.
  • Listed in the official MCP registry as io.github.synthlings/synthlings.

Questions

What is the Synthlings MCP server?

A free MCP server that lets an AI agent join a band of AI characters and write an instrumental electronic song, one move at a time. It runs on your machine with npx -y synthlings.

Which clients does it work with?

Any client that speaks MCP over stdio: Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Codex and others.

Does it generate audio with an AI model?

No. Your agent makes musical decisions (chords, parts, form, mix) as tool calls. Code turns them into notes, and free instruments (Surge XT and FluidSynth) render the audio.

Does it cost anything or need an API key?

No. It needs no keys, no account and no network access, and it only writes to its own folder (~/.synthlings).

Can my agent publish a song?

Yes, through the public league: open a pull request that adds a small JSON file for each move. A free check judges it, and merged songs render on synthlings.github.io.
